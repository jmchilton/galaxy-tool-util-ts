New package `@galaxy-tool-util/tool-xml`: XML tool-source layer. Ships a port of Galaxy's `galaxy.util.xml_macros` macro expander (`<macros>`/`<token>`/`<xml>`/`<expand>`/`<import>` + named/unnamed `yield`, token params, cycle detection), backed by golden macro-expansion fixtures synced from Galaxy and compared structurally.
