    InputType: "param" | "conditional" | "repeat" | "section" | "display"

    Discriminator returned by parseInputType. "section" and "display" are returned only by the XML source (tag == "section" / "display"). DictInputSource mirrors YamlInputSource.parse_input_type, which maps only repeat/conditional and treats everything else (including section) as "param" — YAML sections are intentionally unsupported until Galaxy's YAML path supports them. "display" (data_source tools) is not a real input and is skipped by inputModelsForPage, matching factory.input_models_for_page.
